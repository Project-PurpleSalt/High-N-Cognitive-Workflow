# High-N-Cognitive-Workflow (高N人脑内防沉迷系统)

**High-N** = the iNtuition dimension of MBTI, used here as a casual metaphor for overthinking — **not a clinical or academic construct**.

一个专为高发散（High-N）人群设计的强制认知干预工作流。纯提示词，零代码，零依赖。

模块一不是学术工具，也不产出可引用结论。它的全部价值是**让你从自己的叙事里跳出来**。

## 核心机制

三回合，每回合之间有一道闸门，禁止一口气吐完：

1. **视角切换器** — 不查文献、不装学术。用一句话给你现实里的现象、反例或代价，把内耗掐断；结尾固定抛出可检索关键词，供你自己查证。
2. **语境收割** — 你回「继续」后才启动。从当前语境提炼 CET-6 / 考研英语词汇与句型，含双语翻译与语法拆解，严格锁死大纲。
3. **实战测试** — 你要求时才出。生成同主题全新短文，仿六级阅读出 2 道选择题，附答案解析；答错再加 1 道变式题。

## 💡 使用示例

**User：**
> 我最近陷入了存在主义危机，感觉一切都没有意义，人活着到底为了什么？

**System（第一回合 · 视角切换）：**
> 这句话在现实里通常不是关于宇宙目的的结论，而是一种状态描述：意义感的供给停了。
>
> 你的盲区在于把它当成一个需要被“回答”的问题；它更可能是一个需要被“修复”的供给问题——人不是靠找到答案活着的，是靠持续的投入、关系和具体事务维持意义感的。
>
> 以上是视角切换，不是事实论断；若你要引用，请自行查证关键词「meaning in life 实证研究」「logotherapy」。
>
> 【系统提示】视角已切换，是否继续启动第二回合进行英语语境收割？（回复“继续”即可）

系统**停在这里**。你回「继续」，才输出词表；再回「出题」，才出短文和题目。

## ⚠️ 已知限制（Known Limitations）

- **模块一不提供学术依据**：它不联网、不检索，输出是启发式视角切换，不是事实论断。想要引用，请按它结尾给出的关键词自行查证——那里才是你的信源。
- **MBTI 只是隐喻**：本项目不主张 MBTI 的科学性，“High-N” 只是一个描述过度发散的通俗说法。
- **Token 消耗**：分段输出只节省单次响应长度，长对话上下文依然累积；话题跑得越远，模型遵守闸门的稳定性越差。
- **依赖模型自身纪律**：闸门靠提示词约束，不是代码强制。指令遵循差的模型可能一次吐完三个回合。
- **词汇边界靠模型自律**：“严禁超纲”没有可执行校验器，模型对六级大纲的边界判断存在漂移。

## 使用方法

把 [`prompt.md`](prompt.md) 的**全文**复制进任意支持长文本的大模型（DeepSeek / ChatGPT / Kimi 等），粘贴到 **System Prompt** 位置，即可直接使用。无需安装、无需配置。
