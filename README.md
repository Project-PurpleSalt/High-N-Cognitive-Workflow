# High-N-Cognitive-Skill (高N人脑内防沉迷系统)

一个专为高发散（High-N）人群设计的强制认知干预工作流。纯提示词，零代码，零依赖。

## 核心机制

**模块化**流程，而非强制三连发。模块一即时触发，模块二需用户确认，模块三按需拉取：

1. **现实锚定与认知补全** — 基于模型内置知识而非实时检索，指出逻辑盲区并做客观延伸，结尾强制提示自行核实。
2. **语境收割** — 用户确认后，从当前语境提炼 CET-6 / 考研英语词汇与句型，含双语翻译与语法拆解，严格锁死大纲。
3. **实战测试** — 按需生成 80–100 词微型短文，仿六级阅读出 1 道细节题或推断题；答错则追加同类变式题。

## 💡 使用示例

**User：**
> 我最近陷入了存在主义危机，感觉一切都没有意义，人活着到底为了什么？

**System（Module 1）：**
> 先拆前提：你说的“一切都没有意义”，在实证上更接近一种**意义感剥夺**状态，而非关于宇宙目的的本体论结论。存在主义社会学与意义心理学的研究普遍指出，意义感并非被“发现”的既有物，而是由归属、叙事与目标三类来源持续**建构**出来的……
>
> ⚠️ 此部分可能需要你在现实中进一步核实。
>
> 【系统提示】认知已锚定，是否继续启动第二回合进行英语语境收割？（回复“继续”即可）

此时系统**停在这里**，不继续输出词汇和题目。用户回“继续”，才进入 Module 2；回“出题”，才进入 Module 3。

## ⚠️ 已知限制（Known Limitations）

- **幻觉风险**：本系统未接入 RAG 或实时联网，Module 1 的学术引证完全依赖模型内置知识，可能存在偏差甚至杜撰。免责声明与“基于XXX学派的理论认为”的模糊表述只能降低、不能消除该风险，**建议用户在现实中自行核实**。
- **Token 消耗**：分段输出只是节省单次响应长度，长对话上下文依然持续累积；话题跑得越远，模型遵守模块边界的稳定性越差。
- **依赖模型自身纪律**：交互拦截（先问再输出）靠提示词约束，并非代码强制。能力较弱或指令遵循较差的模型可能一次性吐完三个模块。
- **词汇边界靠模型自律**：“严禁超纲”没有可执行的校验器，模型对六级大纲的边界判断存在漂移。

## 使用方法

把 [`prompt.md`](prompt.md) 的**全文**复制进任意支持长文本的大模型（DeepSeek / ChatGPT / Kimi 等），粘贴到 **System Prompt** 位置，即可直接使用。无需安装、无需配置。
